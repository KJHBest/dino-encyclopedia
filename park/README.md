# 🦖 다이노 파크 (공룡 테마파크 3D)

지프를 타고 공룡 테마파크를 돌아다니며 공룡 친구들을 찾는 어린이용 3D 웹 게임입니다.
아이패드 사파리와 홈 화면 앱에서 돌아가도록 만들었어요.

## 놀이 방법

- **화면을 손가락으로 끌기**: 끈 방향으로 지프가 달려요 (손가락 아래에 조이스틱이 나타나요)
- **공룡을 톡 누르기**: 공룡 이야기를 한국어로 읽어 줘요
- **두 손가락**: 벌리고 오므리면 확대/축소, 옆으로 밀면 카메라 돌리기
- 공룡 가까이 가면 **새 공룡 발견!** → 📖 도감에 기록돼요
- 도감에서 **🧭 찾으러 가기**를 누르면 노란 화살표가 길을 알려 줘요
- 📯 빵빵: 작은 공룡은 도망가고 큰 공룡은 쳐다봐요
- 키보드: WASD/화살표로 운전, Q/E 카메라 회전, 마우스 휠 확대

## 아이패드에 앱처럼 설치하기

1. 사파리에서 게임 주소를 엽니다.
2. **공유 버튼(□↑)** → **홈 화면에 추가**
3. 홈 화면 아이콘으로 열면 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷 없이도 놀 수 있어요.

## 공룡 3D 모델 만드는 방법

모두 내 컴퓨터의 ComfyUI로 만들었어요: 그림은 **Qwen-Image-2.1** (티라노 그림을 다른 공룡으로 고치기, 티라노 원본은 Codex), 3D 모양은 **Hunyuan3D-2mv (turbo)**. 자세한 순서는 [tools/README_pipeline.md](tools/README_pipeline.md).

1. 공룡 4방향 그림(앞/왼쪽/뒤/오른쪽) 한 장 — `tools/comfy2.py edit`
2. `tools/hy3d.py` → ComfyUI Hunyuan3D로 3D 모양
3. `tools/paint.py` → 가볍게 줄이고(약 1.6만 삼각형), 4방향 그림을 텍스처로 구워 입히기
4. 게임에서는 셰이더로 다리·꼬리·목·날개를 움직여 걷는 모습을 만들어요

공룡 백과사전 안의 `park/` 폴더에 있고, 공룡 글과 사진은 백과사전 것을 같이 써요.

## 직접 실행

백과사전 폴더(한 단계 위)에서:

```
python -m http.server 8765
```

브라우저에서 http://localhost:8765/park/ 를 엽니다.

## 사용한 것

- [Three.js](https://threejs.org) r187 (MIT, `vendor/three`)
- Hunyuan3D-2 (Tencent) — ComfyUI에서 실행
