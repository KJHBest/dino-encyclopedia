# 🦖 공룡 백과사전

그림과 짧은 설명, 음성 읽어주기로 만나는 어린이용 공룡 백과사전입니다.

- 공룡 100종 (익룡·바다 파충류 포함, 우리나라 공룡 3종 포함): 이름 뜻, 시대, 식성, 크기, 발견 장소
- 🔊 읽어주기: 브라우저 음성 합성(Web Speech API)으로 한국어로 읽어줘요. 속도 조절 가능
- ▶ 계속 넘기며 읽기: 다 읽으면 다음 공룡으로 넘어가서 계속 읽어줘요
- 검색, 시대/식성 필터, 🎲 랜덤 공룡
- 그림은 Codex(이미지 생성)로 그린 상상도입니다

## 아이패드에 앱처럼 설치하기

1. 사파리에서 https://kjhbest.github.io/dino-encyclopedia/ 를 엽니다.
2. 위쪽 **공유 버튼(□↑)** → **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 🦖 "공룡 백과" 아이콘으로 열면 주소창 없이 앱처럼 열려요.

한 번 열면 그림과 글이 기기에 저장되어 인터넷 없이도 볼 수 있어요.
아이에게 사파리를 막아 두었다면, 설정 → 스크린 타임 → 콘텐츠 및 개인정보 보호 제한 → (콘텐츠 제한) → 웹 콘텐츠 →
**"허용된 웹 사이트만"**에 `https://kjhbest.github.io/dino-encyclopedia/` 를 추가하는 방법도 있어요.

## 열어보기

`index.html`을 브라우저로 열거나, 로컬 서버로 실행하세요.

```
python -m http.server 8765
```

## 공룡 추가하기

1. `data.js`에 항목을 추가합니다 (`id`가 그림 파일 이름).
2. `images/<id>.png`를 넣고 `python tools/convert_images.py`로 WebP(본 그림 + 썸네일)로 변환합니다.

GitHub Pages로 배포하면 인터넷만 되면 어디서든 접속할 수 있어요.
